# StudioManager v2.0 -- UI/UX Redesign Brief

## Vision

StudioManager bukan lagi sekadar dashboard freelancer, tetapi **Creative
Operating System** untuk studio independen.

Design Keywords: - Minimal - Premium - Fast - Calm - Focused -
Editorial - Linear-inspired - Vercel-inspired

------------------------------------------------------------------------

# Core Design Principles

1.  Typography First
2.  Banyak whitespace
3.  Maximum 1 accent color (Purple)
4.  Card seminimal mungkin
5.  Semua action dapat dicapai ≤2 klik
6.  Fokus pada pekerjaan hari ini, bukan sekadar statistik

dan alur kerja agar terasa seperti aplikasi premium modern ala Linear,
Vercel, dan Arc Browser.
